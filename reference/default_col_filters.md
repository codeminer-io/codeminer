# Default column filters

Returns the default filtering parameters for all registered lookup,
mapping, and relationship tables. Equivalent to
`get_col_filters(defaults_only = TRUE)`.

## Usage

``` r
default_col_filters()
```

## Value

A named list. See
[`get_col_filters()`](https://codeminer-io.github.io/codeminer/reference/get_col_filters.md)
for details.
