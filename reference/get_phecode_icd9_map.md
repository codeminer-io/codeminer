# Download the Phecode 1.2 to ICD9 mapping file

Download link obtained from
https://github.com/PheWAS/PheWAS/tree/master.

## Usage

``` r
get_phecode_icd9_map(path = file.path(tempdir(), "phemap.rda"))
```

## Arguments

- path:

  Path where file will be downloaded to.

## Value

File path to downloaded file.

## Examples

``` r
if (FALSE) { # \dontrun{
get_phecode_icd9_map()
} # }
```
