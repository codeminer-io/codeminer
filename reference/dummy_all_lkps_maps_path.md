# Dummy UK Biobank resource 592 file path

Returns the file path to a dummy [UK Biobank resource
592](https://biobank.ndph.ox.ac.uk/ukb/refer.cgi?id=592) excel
spreadsheet.

## Usage

``` r
dummy_all_lkps_maps_path()
```

## Value

A string.
